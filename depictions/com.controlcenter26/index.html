ControlCenter26

com.controlcenter26 · 1.1

Description

A Control Center similar to iOS 26.

ControlCenter26 reshapes Control Center to look and behave like the one in iOS 26: resizable and reorderable modules, connectivity buttons, media and page controls, and smoother animations.

Settings ▸ Control Center holds the options.

Packages for rootless (iphoneos-arm64) and roothide (iphoneos-arm64e) jailbreaks. Requires iOS 14.0 to 17.3, ellekit or MobileSubstrate, CCSupport (com.opa334.ccsupport) and PreferenceLoader.

Changelog

1.1

Landscape

  • Control Center pages its modules by column in landscape, like iOS 26. Swipe left or right to move between pages; it returns to the first page when you rotate.
  • The Connectivity page uses the same wide layout as the expanded Connectivity module.
  • The Music page and the expanded Music module use a wide card in landscape: artwork on the left, controls on the right.
  • Fixed the sizes of the expanded Connectivity and Music modules in landscape.
  • Fixed dark boxes behind some modules in landscape.
  • Notched screens are detected the same way in both orientations.

Connectivity module

  • Removed the extra glass from Connectivity buttons that are off.

Packaging

  • Package com.controlcenter26 1.1 for roothide (arm64e) and rootless (arm64 and arm64e).
  • Depends on ellekit or mobilesubstrate, CCSupport (com.opa334.ccsupport) and PreferenceLoader.

1.0

Connectivity module

  • Expanding and folding starts from the tile's real on-screen position, so the animation no longer jumps.
  • Collapsing puts the Airplane, Wi-Fi and AirDrop buttons in place at once and fades them in, so the Wi-Fi button no longer slides to the wrong spot.
  • The stock cellular glyph is hidden at its enlarged size.
  • The + button opens Settings much faster: Control Center closes first, then Settings opens.

Page icons

  • The pages don't move while a page icon is held or dragged.
  • Icons ignore touches while Control Center is still scrolling, so a running scroll is not cut off.
  • The scroll lock is released when the touch ends outside the icon or Control Center closes mid-hold.

Media module

  • Grey plates behind artwork and AirPlay over light wallpaper, for readable text.

Other

  • Author and About text now credit imod_commission.

Known issues

  • A page icon can still disappear in some conditions. Not yet reproduced.
  • A swipe made within about one second after releasing a page icon is not blocked.

0.0.8a

  • Connectivity module: expand and fold start from the tile's real rect; buttons no longer slide or snap when collapsing.
  • Stock cellular glyph hidden at its enlarged size.
  • Settings opens from the + button without lag.
  • Page icons: scrolling is locked while an icon is held; a running scroll is not cut off.
  • Media module: grey plates behind artwork and routing backgrounds over light wallpaper.
